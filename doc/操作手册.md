# ImageToolBox 操作手册

> 适用版本：0.1.0｜更新日期：2026-07-31｜适用平台：Web/PWA、Windows、macOS、Linux

## 1. 产品简介

ImageToolBox 是一款轻量、本地优先的图片编辑器。图片导入、编辑、工程保存和结果导出均在本地完成，无需把图片上传到远程处理服务。

主要能力：

- 导入、拖放或粘贴多张图片
- 移动、缩放、旋转和无损裁剪
- 添加文字、矩形、椭圆、直线、箭头、画笔和荧光笔
- 管理图层顺序、显示状态和锁定状态
- 设置固定画布、透明背景或自动适应内容
- 自动恢复本地草稿，支持撤销与重做
- 保存和打开 `.ibox` 工程
- 导出 PNG、JPG 或 WebP
- 中英文界面及触屏操作

## 2. 启动应用

### 2.1 Web/PWA

在浏览器中打开部署地址即可使用。支持 PWA 的浏览器可通过地址栏或浏览器菜单将应用安装到桌面。

首次加载需要网络获取应用资源。完成缓存后，已安装的 PWA 可在离线状态下打开，但浏览器清理站点数据后需要重新加载。

### 2.2 桌面版

各平台提供以下安装包：

| 平台 | 产物 |
| --- | --- |
| Windows x64 | 便携版 `.exe`、免安装 `.zip` |
| macOS x64 / arm64 | `.dmg`、`.zip` |
| Linux x64 | `.AppImage`、`.deb`、`.rpm` |

Windows 便携版无需安装，直接运行 EXE 即可。ZIP 版本解压后运行其中的应用程序。

### 2.3 本地开发运行

建议使用 Node.js 22 和 pnpm 10.11.0。

```bash
pnpm install
pnpm dev
```

桌面端开发：

```bash
pnpm dev:desktop
```

## 3. 界面说明

编辑器由五个主要区域组成：

| 区域 | 作用 |
| --- | --- |
| 顶部命令栏 | 工程重命名、撤销、重做、导入、新建、打开、保存、语言切换和导出 |
| 左侧工具栏 | 选择编辑工具或创建对象 |
| 中央画布 | 显示并编辑图片、文字和图形 |
| 右侧面板 | 编辑对象属性、背景和图层 |
| 底部状态栏 | 调整缩放、适应画布、查看坐标和本地处理状态 |

在较窄的窗口或移动设备上，属性和图层面板会通过底部按钮打开。

## 4. 推荐工作流程

1. 新建工程或打开已有 `.ibox` 工程。
2. 导入、拖放或粘贴图片。
3. 调整图片位置、尺寸、旋转和图层顺序。
4. 使用裁剪、文字、形状或绘图工具补充内容。
5. 设置画布尺寸和背景。
6. 将可继续编辑的版本保存为 `.ibox`。
7. 将最终结果导出为 PNG、JPG 或 WebP。

> 自动保存主要用于恢复当前设备中的编辑进度，不等同于备份。重要内容请保存为 `.ibox` 工程文件。

## 5. 导入图片

支持的图片格式：

- JPEG / JPG
- PNG
- WebP
- BMP

### 5.1 使用导入按钮

单击顶部的“导入”或左侧“导入图片”，在文件选择器中选择一张或多张图片。

### 5.2 拖放导入

把图片文件直接拖入编辑器。多张图片可以同时拖入。

### 5.3 从剪贴板粘贴

在编辑器中按 `Ctrl+V` 或 `⌘+V`。如果剪贴板中包含图片，应用会将其作为新图层导入；普通文本不会被导入。

### 5.4 导入后的行为

- 新图片会自动创建图片图层并被选中。
- 超过显示区域的大图会按比例缩小显示，但工程仍保留原始图片资源。
- 第一张图片导入后，视图会自动适应当前内容。
- 导入 `.ibox` 文件时，当前工程会被该工程替换。

## 6. 选择、移动与变换

### 6.1 选择对象

- 单击对象：选中该对象。
- `Shift + 单击`：追加或取消多选。
- 单击空白处：清除当前选择。
- 在图层列表中单击：选择对应图层。

### 6.2 移动对象

选中对象后直接拖动。也可以在右侧属性面板中输入精确的 X、Y 坐标。

锁定的对象不能在画布上变换。

### 6.3 缩放与旋转

- 拖动选框控制点调整宽高。
- 拖动旋转控制点调整角度。
- 在属性面板中输入宽度、高度或旋转角度可进行精确调整。
- 调整对象不透明度可制作叠加效果。

### 6.4 复制和删除

- `Ctrl/⌘+D`：复制选中对象。
- `Delete` 或 `Backspace`：删除选中对象。

删除图片图层后，如果其原始资源不再被其他图层引用，自动保存时会清理对应的本地资源。

## 7. 画布导航

### 7.1 缩放

- 使用鼠标滚轮围绕指针位置缩放。
- 使用底部的 `−`、`+` 或滑块调整缩放。
- 单击“适应”让当前文档完整显示在编辑区域。
- 编辑器支持约 10% 至 300% 的视图缩放。

缩放只影响编辑视图，不会降低导出图片的质量。

### 7.2 平移

- 选择“平移”工具后拖动画布。
- 按住空格键可临时进入平移模式，松开后返回原工具。
- 触屏设备可使用双指移动视图。

### 7.3 触屏手势

双指手势支持同时缩放和平移，缩放中心会跟随两指中点。

## 8. 工具说明

### 8.1 选择

用于选择、移动、缩放和旋转对象。快捷键：`V`。

### 8.2 裁剪

用于调整图片的可见区域。快捷键：`C`。

只有选中单个图片图层时才能进入裁剪模式。裁剪不会修改原始图片资源。

### 8.3 文本

选择文本工具后，在画布上单击放置文本。快捷键：`T`。

创建前可设置：

- 默认文字
- 文本框宽度
- 字号与字重
- 左对齐、居中或右对齐
- 文字颜色

创建后可在属性面板中修改文字内容、字号、颜色、位置、尺寸、角度和不透明度。

### 8.4 矩形

在画布上拖动绘制矩形。快捷键：`R`。

可设置描边开关、颜色、粗细、实线/虚线、填充颜色、填充不透明度和圆角。按住 `Shift` 拖动可绘制正方形。

### 8.5 椭圆

在画布上拖动绘制椭圆。可设置描边和填充。按住 `Shift` 拖动可绘制圆形。

### 8.6 直线

拖动起点和终点创建直线。可设置颜色、粗细以及实线或虚线。

### 8.7 箭头

拖动创建箭头，可设置线条颜色、粗细、线型和箭头大小。

### 8.8 画笔

按住并拖动进行自由绘制。快捷键：`P`。可设置颜色、笔触粗细和不透明度。

### 8.9 荧光笔

用于绘制半透明的宽笔触。可设置颜色、粗细和不透明度。

### 8.10 工具预设

创建类工具的设置会应用于“下一个新对象”，不会修改当前选中的对象。工具预设会保存在本地，可通过设置面板的重置按钮恢复默认值。

## 9. 图片裁剪

1. 选择一个图片图层。
2. 单击“裁剪”或按 `C`。
3. 选择自由比例、原图比例或其他常用比例。
4. 拖动裁剪框或控制点调整区域。
5. 使用“缩放图片内容”滑块调整可见范围。
6. 单击“完成”或按 `Enter` 应用。

其他操作：

- 单击“取消”或按 `Esc`：放弃本次裁剪。
- 单击“重置”：恢复完整原图。

裁剪只更新图片的显示区域，因此后续仍可重新裁剪或恢复原图。

## 10. 对象属性

右侧属性面板会根据对象类型显示可编辑内容。

### 10.1 通用属性

- X、Y 位置
- 宽度、高度
- 旋转角度
- 不透明度

### 10.2 图片属性

- 边框开关
- 边框颜色和宽度
- 圆角

### 10.3 形状属性

- 描边开关、颜色和宽度
- 填充开关、颜色和不透明度

### 10.4 线条和箭头属性

- 线条颜色
- 线条宽度

### 10.5 自由绘制属性

- 笔触颜色
- 笔触宽度

### 10.6 文字属性

- 文字内容
- 字号
- 文字颜色

## 11. 背景与画布

### 11.1 背景层

背景是独立图层，默认状态为：

- 白色
- 可见
- 锁定
- 自动适应可见内容

背景层可在图层面板中重命名、隐藏或解锁。

### 11.2 自动适应大小

启用后，背景范围会自动采用所有可见对象的外接范围。隐藏的对象不会影响背景范围。

### 11.3 固定画布尺寸

先解锁背景并关闭“自适应大小”，然后选择预设或输入自定义尺寸。

内置预设：

| 预设 | 尺寸 |
| --- | --- |
| 方形 | 1080 × 1080 |
| 横屏 16:9 | 1920 × 1080 |
| 竖屏 9:16 | 1080 × 1920 |
| 社交媒体 4:5 | 1080 × 1350 |

“交换宽高”可快速切换横向和纵向尺寸。

### 11.4 在画布中变换背景

解锁背景后，可启用“在画布中拖动/缩放”。启用时会关闭自动适应，然后可像普通对象一样拖动背景或调整其边界。

### 11.5 透明背景

开启“透明背景”后，画布显示棋盘格。PNG 和 WebP 可保留透明度；JPG 不支持透明背景，导出时会自动使用白色填充。

## 12. 图层管理

图层面板包含所有编辑对象和背景层。

可执行的操作：

- 单击选择图层
- `Shift + 单击`多选
- 拖动改变图层顺序
- 使用“上移”或“下移”调整一层
- 单击眼睛图标显示或隐藏
- 单击锁图标锁定或解锁
- 双击名称或单击重命名按钮修改名称
- 删除当前选中的普通图层

图层列表越靠上，视觉上越接近前景。

## 13. 撤销与重做

- 撤销：`Ctrl/⌘+Z`
- 重做：`Ctrl/⌘+Shift+Z`

当前历史记录最多保存 50 个可撤销操作。打开或新建工程后，原工程的撤销历史不会保留。

## 14. 工程管理

### 14.1 工程名称

单击顶部工程名称即可重命名。工程名称会作为保存 `.ibox` 和导出图片时的默认文件名。

### 14.2 新建工程

单击“新建”。如果当前画布存在内容，应用会要求确认。

新建工程会清空当前画布，并替换本地自动恢复的工程。需要保留的内容请先保存为 `.ibox`。

### 14.3 保存工程

单击“保存工程”或按 `Ctrl/⌘+S`。

工程文件扩展名为 `.ibox`，其中包含：

- 工程清单
- 画布和图层数据
- 原始图片资源

`.ibox` 用于以后继续编辑，不是普通图片文件。

### 14.4 打开工程

单击“打开”，选择 `.ibox` 文件。成功打开后，当前画布、资源和本地恢复内容都会切换到该工程。

### 14.5 自动保存与恢复

每次正式编辑后，应用都会把当前工程保存到本地浏览器存储。下次打开同一应用来源时，会自动尝试恢复。

以下情况可能导致草稿丢失：

- 清理浏览器站点数据
- 使用无痕/隐私窗口后关闭窗口
- 更换浏览器、系统用户或设备
- 浏览器存储空间不足或被系统清理

因此，自动保存不能替代 `.ibox` 文件备份。

## 15. 导出图片

单击“导出”或按 `Ctrl/⌘+E`。

### 15.1 格式

| 格式 | 适用场景 | 说明 |
| --- | --- | --- |
| PNG | 透明背景、界面图、需要无损保存 | 支持透明度 |
| JPG | 照片、较小文件 | 不支持透明度，可调质量 |
| WebP | Web 使用、兼顾体积和质量 | 支持质量设置 |

### 15.2 倍率

- `0.5×`：减小像素尺寸和文件体积
- `1×`：按当前文档范围导出
- `2×`：生成双倍像素尺寸

### 15.3 导出范围

- 默认导出完整可见文档。
- 勾选“仅导出选中对象”后，只导出当前选中对象的外接范围。
- 没有选中对象时，该选项不可用。
- 隐藏图层不会进入导出结果。

### 15.4 输出质量

JPG 和 WebP 可通过质量滑块调整压缩质量。PNG 不显示质量选项。

导出使用原始图片资源重新合成，不是对当前屏幕画面的截图，因此编辑器缩放不会影响输出清晰度。

## 16. 语言切换

应用支持中文和英文：

- 单击顶部语言按钮切换。
- 桌面端也可以使用“Language/语言”菜单。
- 语言设置会保存在本地。

首次打开时，应用会根据系统或浏览器语言选择中文或英文。

## 18. 隐私与本地数据

当前版本没有图片上传、云端处理、账号同步或遥测功能。

本地可能保存以下数据：

- 当前工程及其图片资源：IndexedDB
- 当前工程指针：localStorage
- 界面语言：localStorage
- 工具预设：localStorage

Web 版仍可能通过部署服务器获取应用静态资源；“本地处理”指用户图片与工程内容不需要上传到远程处理服务。

## 19. 常见问题

### 19.1 图片无法导入

确认图片为 JPEG、PNG、WebP 或 BMP，并且文件未损坏。GIF、SVG、TIFF、HEIC 当前不支持直接导入。

### 19.2 JPG 导出后背景变白

JPG 不支持透明度。需要透明背景时请使用 PNG 或 WebP。

### 19.3 找不到上次编辑内容

检查是否使用了相同的浏览器、站点地址和系统用户。浏览器站点数据被清理后，本地草稿无法恢复，请使用之前保存的 `.ibox`。

### 19.4 `.ibox` 无法打开

文件可能损坏、资源缺失或来自不兼容的未来版本。请尝试重新复制或重新保存原工程。

### 19.5 画布尺寸无法修改

先在背景属性中解锁背景，并关闭“自适应大小”。

### 19.6 对象无法拖动或缩放

检查对象或背景是否被锁定。裁剪模式下也需要先完成或取消裁剪。

### 19.7 PWA 没有立即更新

应用使用提示更新策略。接受更新提示，或关闭所有旧页面后重新打开。

### 19.8 macOS 提示应用来源不明

当前自动构建产物可能未签名或未公证。测试时可按系统安全设置处理；正式分发版本应配置 Apple 签名与公证。

## 20. 当前限制

- 仅支持 JPEG、PNG、WebP、BMP 图片导入。
- 不支持动画图片编辑。
- 不支持云端同步、多人协作和跨设备草稿同步。
- 不提供滤镜、色阶、蒙版、混合模式或复杂路径编辑。
- 桌面端尚未启用大图模式、文件夹批处理、后台任务和原生图片编解码。
- `.ibox` 当前格式版本为 1。

## 21. 开发与发布命令

```bash
pnpm typecheck       # 类型检查
pnpm test            # 自动化测试
pnpm build:web       # 构建 Web/PWA
pnpm build           # 构建 Web 和桌面渲染器
pnpm dist:win        # Windows EXE/ZIP
pnpm dist:mac        # macOS DMG/ZIP
pnpm dist:linux      # Linux AppImage/DEB/RPM
```

推送到 `main` 会触发 GitHub Pages 部署。手动运行 **Build Electron** 工作流可生成各平台安装包；推送 `v*` 标签会构建安装包并创建或更新 GitHub Release。
